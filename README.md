Navegación:
La pagina cuenta con un menú principal que permite acceder a 2 paginas aparte, una de registro de pedidos y otra de consulta de pedidos.
En la pagina de registro, se ingresan datos a través de un formulario, luego, esta información se guarda en un archivo formato csv.
En la pagina de consulta, se pregunta por el nombre del pedido, y si el pedido existe en los registros, devuelve la información del pedido.
